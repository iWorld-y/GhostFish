GHOSTFISH / DESIGN SYSTEM

组件与设计规范

从现有界面提取规则，为后续改动提供可追溯的依据。

01

基础规范

保留中性浅灰和深灰背景。窗口背景来自应用源码，其他颜色对应框架的语义角色，具体色值为本网页的映射。

02

字体与尺寸

字体层级

设置 / 网站需要身份验证不透明度范围与窗口拖动修饰键快捷键可能与其他应用共享，或被系统拦截。

标题 18px、说明 12px 为源码显式值。常规控件 14px 与系统字体栈是网页映射。

间距与图标

间距4 / 6 / 8 / 12 / 16 / 20
标签栏最小高度36px
标签文字最大宽度160px
新增 / 设置 / 关闭按钮宽32 / 36 / 28px
图标尺寸 / 线宽18px / 1.6

保持源码中的 6px 间距，不强行改为统一的 8px 倍数。

03

控件与状态

按钮

主要动作使用强调色；次要操作使用中性表面。按 Tab 可查看焦点，点击登录可查看加载状态。

图标按钮

新增和设置 SVG 来自关联源码；关闭图标采用同一线宽。所有图标按钮提供可访问名称。

输入框

焦点使用明确轮廓。错误同时显示文字，不能仅依靠边框颜色。

复选框与辅助信息

窗口拖动：请至少选择一个修饰键

实际设置允许四个修饰键多选，开始拖动时要求组合完全匹配。

标签页

macOS 当前标签为完整高度的直角背景，两侧细线。仅当前标签显示关闭按钮；点击可以切换。

快捷键

录入态显示“请按快捷键”。完整的录入、重复校验和取消流程位于设置原型。

组件可点击，操作仅影响本页演示。

04

交互组合

认证失败

保留输入，显示源码中的错误文案。示例只使用虚构账号。

正在验证

验证期间禁用用户名、密码与登录按钮，保留取消入口。

托盘菜单

保存的穿透配置与临时暂停分开显示。隐藏时只更换显示操作，不清除标签。

设置校验与失败

请输入 0% 至 100% 的整数，且下限不能大于上限

切换穿透：快捷键不能重复

恢复快捷键失败：切换穿透

不可用

输入校验在原型中可操作；系统注册与恢复失败在此展示状态，不执行真实注册。

05

维护约定
