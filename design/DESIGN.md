## 3. 设计方向与结构

保留现有桌面工具的紧凑界面。浏览内容占据主要空间，标签栏只提供标签管理与设置入口。使用中性背景、细边框、低装饰密度和有明确意义的状态提示。

不因建立设计系统而增加产品首页、侧边导航、统计卡片、搜索功能或常驻网址工具栏。原型外层的导航仅用于阅读设计产物。

### 3.1 界面层级

```text
应用
├─ 主浮动窗口
│  ├─ 标签栏
│  │  ├─ 平台窗口控件预留区域
│  │  ├─ 可横向滚动的标签列表
│  │  ├─ 新建标签按钮
│  │  ├─ 可拖动的空白区域
│  │  └─ 设置按钮，仅 macOS
│  ├─ 地址栏，仅尚未打开网页的新标签
│  ├─ 导航错误提示，存在错误时显示
│  └─ 当前标签的 WebView
├─ 设置模态层，仅 macOS
├─ 当前标签对应的独立认证窗口
└─ 系统托盘菜单
```

主窗口初始参考尺寸为 `960 × 720`，默认置顶，使用隐藏标题栏。源码通过平台提供的标题栏左右预留量避让原生窗口按钮。

HTML 画布以该尺寸为参考，并在可用空间内调整宽高。窄屏将设计导航排成横向滚动区域，组件展示改成单列。窄屏适配属于文档与原型容器的行为，不代表产品存在手机版。

### 3.2 主原型场景

| 场景 | 起始状态 | 主要操作 |
| --- | --- | --- |
| 浮动浏览器 | 示例网页和一个空白标签 | 切换、新建、关闭标签，打开设置 |
| 新标签页 | 空白内容和已聚焦的地址输入 | 输入网址并按 Enter |
| 窗口设置 | 当前生效设置的草稿 | 修改范围、录入快捷键、选择修饰键、保存或取消 |
| 身份验证 | 独立认证窗口和另一个可切换标签 | 输入、切换标签、取消、演示成功或失败 |
| 导航失败 | 保留目标地址和错误信息 | 修改网址后重试 |
| 鼠标穿透 | 主窗口不接收页面内点击 | 从外部演示托盘恢复 |
| 隐藏与恢复 | 主窗口隐藏，标签仍在 | 从托盘或演示恢复按钮显示窗口 |

浏览器场景默认展示示例网页，便于观察视觉样式。原生应用不带 URL 启动时应显示空白标签，对应原型中的“新标签页”场景。

## 4. 视觉规范

### 4.1 字体与排版

| 用途 | 源码依据 | 网页变量与处理 |
| --- | --- | --- |
| 设置、认证标题 | `FontSize(18).Bold()` | `--text-title: 18px`，粗体 |
| 设置快捷键提示 | `FontSize(12).Wrap()` | `--text-xs: 12px`，允许换行 |
| macOS 标签关闭文字 | `FontSize(18)` | HTML 使用同尺寸级别的线性关闭图标，属于映射 |
| 常规标签、字段与按钮 | 未显式指定字号，使用框架默认值 | `--text-ui: 14px`，不是已确认的原生默认字号 |
| 字体家族 | 依赖框架默认字体，关联仓库未显式定义 | 优先系统字体，macOS 使用系统可用字体 |
| 展示页说明和主标题 | 不属于原生应用 | 基础正文 16px，主标题 24px 至 32px |

网页字体栈见 `--font-ui`。正文使用 `-apple-system`、`BlinkMacSystemFont`、`SF Pro Text`、`PingFang SC` 等可用系统字体，代码说明使用 `--font-mono`。无需下载字体。

为保留现有桌面控件密度，原型沿用源码中明确的 12px、18px 层级，并以 14px 映射普通控件。该处理是对通用网页正文 16px 基线的有意区分，不应据此把普通文档正文也缩小。

标签标题单行显示，最大宽度 160px；溢出时省略，并通过完整可访问名称和提示保留标题。错误与解释文本换行，不用截断隐藏必要信息。

### 4.4 图标和动效

新建与设置图标取自 `browser_ui_mac.go` 的内联 SVG，保留线宽和圆形端点。网页关闭图标与其使用同一线性风格；原生源码使用“×”文本。窗口三色按钮是对平台控件的网页示意，不是复制的系统控件。

原型的表面和不透明度过渡采用 160ms，并尊重 `prefers-reduced-motion`。这属于网页映射，源码没有声明对应时长。导航与认证示例中的短暂等待仅用于展示状态，不表示实际网络延迟。

## 5. 核心交互流程

### 5.1 标签与地址栏

1. 新建标签后选中该标签，并将焦点放入地址栏。原生应用不带 URL 启动时遵循同样的空白标签路径。
2. 提交地址后补全缺省协议并校验。未显式填写协议时补 `https://`，拒绝非 HTTP/HTTPS 协议，不提供关键词搜索。
3. 主文档提交后，将标签标记为已打开网页并隐藏地址栏。以后切回该标签也不常驻显示地址栏。
4. 首次加载失败时保留原输入，恢复地址栏并显示错误。修改输入会清除该错误；再次提交后进入新的导航。

原生的 `startupLoading` 另有地址栏显隐逻辑。原型覆盖手动提交路径，没有重现带启动参数的完整异步生命周期。

切换标签保留各标签的输入和认证状态。关闭活动标签时选中删除位置上的后继标签；若不存在后继，则选中前一标签。关闭最后一个标签会关闭窗口并退出。原型将退出呈现为可重新开始的演示状态，不尝试关闭浏览器标签。

### 5.2 设置草稿与快捷键录入

| 操作 | 生效状态 | 草稿与界面 |
| --- | --- | --- |
| 打开设置 | 原配置继续生效，穿透暂时暂停 | 从当前配置建立新草稿 |
| 修改字段 | 不立即保存 | 更新草稿 |
| 开始录入快捷键 | 原生临时释放相关快捷键 | 显示“请按快捷键”，焦点进入录入按钮 |
| 录入时按 Escape | 恢复录入前的快捷键 | 只退出录入，不关闭设置 |
| 保存且校验通过 | 应用新配置，将当前不透明度限制到新范围 | 关闭设置 |
| 输入或注册失败 | 原生保留或恢复可用的旧配置 | 保留输入并显示错误 |
| 取消、关闭或普通 Escape | 不保存草稿 | 结束录入并关闭设置 |

不透明度上下限是 0% 至 100% 的整数，下限不能大于上限。上下限相同表示固定不透明度。原型中的滑块属于外部演示工具，不是原生设置页新增的控件。

拖动组合可以包含 Command、Control、Option、Shift 中的一个或多个键，至少选一个。原生开始拖动时要求实际按下状态与选定组合完全一致。

四组快捷键至少包含 Command、Control 或 Option 中的一个，可附加 Shift。主键支持字母、数字、`-`、`=`、空格和 `F1` 至 `F12`，四组不能重复。

| 动作 | macOS 默认组合 |
| --- | --- |
| 降低不透明度 | `⌘ ⇧ -` |
| 提高不透明度 | `⌘ ⇧ =` |
| 切换穿透 | `⌘ ⇧ T` |
| 隐藏 / 显示 | `⌘ ⇧ H` |

原型能在网页获得焦点时录入组合，并完成范围、重复和修饰键校验。浏览器或系统占用的组合可能无法传入网页；原型不注册全局快捷键，也不模拟真实注册成功。

### 5.3 身份验证

独立认证窗口在创建时设为置顶、不透明，默认宽 420、高 340。标题为“网站需要身份验证”，显示主机及存在的认证范围，用户名自动获得焦点，密码使用遮挡输入。原生认证范围超过 100 个字符时截断。

| 状态 | 输入与操作 | 转换 |
| --- | --- | --- |
| 等待输入 | 用户名、密码和登录可用 | 提交后验证；用户名为空时显示错误 |
| 正在验证 | 输入与登录禁用，取消可用 | 显示“正在验证…” |
| 认证失败 | 保留输入，重新启用登录 | 显示“账号或密码不正确，请重试。” |
| 切至其他标签 | 隐藏原标签的认证窗口 | 切回后恢复输入与错误 |
| 取消、关闭标签或重新导航 | 取消关联认证请求 | 丢弃该次认证流程 |

原生独立窗口不与主窗口共用透明度和穿透状态。HTML 也将其放在主窗口容器之外；在有限画布中并列或换行排列，不能据其网页位置推断操作系统窗口坐标。

演示使用 `protected.example.com`。外部结果选择器可选择“认证失败”或“认证通过”；这是人为选择的演示结果，与输入密码无关。账号和密码只存在于当前页面的内存中，不发送、不写入本地存储，也不接触钥匙串。

### 5.4 透明度、穿透与隐藏

默认不透明度为 85%，快捷键每次改变 10 个百分点。macOS 使用设置中生效的范围；Windows/Linux 固定为 20% 至 100%。整窗变淡，文字也随之变淡。

“隐藏”保留标签和网页状态，“退出”结束应用。托盘菜单包含鼠标穿透、隐藏/显示、分隔线和退出。隐藏后操作文案变为“显示窗口”。

托盘中的穿透勾选表示保存的配置。设置打开时，实际穿透暂时暂停，菜单可显示“设置打开时暂时暂停”。原型分别呈现配置与有效状态，避免把暂时暂停误认为用户关闭了配置。

原生进入穿透或隐藏前依赖可恢复入口。托盘不可用时，需有对应的可用快捷键；恢复入口丢失时，桌面控制器会执行保护逻辑。原型始终保留外部演示托盘，不实现系统托盘宿主探测或快捷键恢复失败的全过程。

## 9. 后续维护规则

### 9.1 变更顺序

1. 先定位对应源码符号，确认当前目录是否仍与本文一致。发现 README、历史记录与源码不同，应记录差异并以本次任务指定的来源为准。
