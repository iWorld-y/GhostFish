# Spec Delta

## MODIFIED Requirements

### Requirement: 窗口顶部提供标签栏和新标签页地址栏

应用 SHALL 在网页内容之外显示标签栏，并仅在当前标签页尚未打开网页时显示地址栏。标签栏与窗口按钮位于同一行；地址栏可见时位于下一行，窗口保留可拖动区域。macOS 标签栏右侧 SHALL 提供设置入口，并为平台窗口按钮留出空间。Windows 和 Linux 沿用现有标签栏行为。

#### Scenario: macOS 窗口布局

- **WHEN** 用户打开 macOS 窗口
- **THEN** 原生红绿灯按钮位于标签栏左侧；新标签页的地址栏位于标签栏下方，网页显示在其下方

#### Scenario: 其他平台的窗口按钮

- **WHEN** 用户在 Windows 或 Linux 打开窗口
- **THEN** 标签栏为平台显示的窗口按钮留出空间，已显示的按钮仍可正常使用

#### Scenario: 拖动窗口

- **WHEN** 用户拖动标签栏中用于拖动的空白区域
- **THEN** 窗口跟随移动，标签和地址栏仍可操作

#### Scenario: 打开设置

- **WHEN** 用户在 macOS 点击标签栏右侧的设置入口
- **THEN** 应用打开设置界面，不改变当前标签和网页状态

#### Scenario: 窄窗口或标签过多

- **WHEN** macOS 窗口宽度较窄或标签页数量超出可用宽度
- **THEN** 设置入口、平台窗口按钮、新建标签按钮和拖动区域仍可使用，标签列表仍可横向滚动

### Requirement: 用户可以管理多个标签页

应用 SHALL 支持创建、切换和关闭标签页。每个标签页保留自己的网页状态，标签栏 SHALL 显示可区分的名称。macOS 当前标签 SHALL 使用直角轮廓、占满标签栏高度并在内部显示关闭按钮，标签两侧以必要的竖线分隔；其他平台的当前标签保留上角圆润的轮廓。未选中标签 SHALL 平铺并以必要的竖线分隔。`+` 紧随标签列表，标签过多时 SHALL 保持可访问并可横向滚动。

#### Scenario: 新建空白标签页

- **WHEN** 用户点击标签栏中的 `+`
- **THEN** 应用打开并选中新空白标签页，地址栏获得输入焦点

#### Scenario: 切换标签页

- **WHEN** 用户从一个标签页切换到另一个标签页后再切回
- **THEN** 原标签页仍保留切换前的网页和滚动位置；已经打开网页的标签页不显示地址栏

#### Scenario: 关闭非最后一个标签页

- **WHEN** 用户关闭当前标签页且窗口中仍有其他标签页
- **THEN** 被关闭的标签页及其网页被移除，窗口继续显示一个未关闭的标签页

#### Scenario: 关闭最后一个标签页

- **WHEN** 用户关闭窗口中最后一个标签页
- **THEN** 窗口关闭，应用退出

#### Scenario: macOS 标签栏样式和悬停

- **WHEN** 用户在 macOS 查看标签栏或将指针移到任一标签
- **THEN** 当前标签以直角占满标签栏高度，关闭图标在关闭按钮内水平和垂直居中，悬停反馈覆盖整个标签

#### Scenario: macOS 新建标签按钮

- **WHEN** 用户在 macOS 查看或悬停新建标签按钮
- **THEN** 按钮占满标签栏高度，加号在按钮内水平和垂直居中，悬停反馈覆盖按钮
