# Proposal

## Why

HTTP Basic 认证目前使用独立置顶窗口。主窗口隐藏或开启鼠标穿透时，认证窗口仍可能显示并接收鼠标，无法作为标签页内容随主窗口操作。

## What Changes

- 在发起认证的标签页内容区域显示认证表单，保留标签栏供切换。
- 切换标签页时保留各自的认证状态和输入，仅显示当前标签页的表单。
- 认证表单随主窗口的可见、穿透和不透明度状态变化。
- 保留现有的凭据来源、校验、取消和安全存储逻辑。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `http-auth`：调整认证表单的显示位置和与标签页、主窗口的关系。

## Impact

涉及 `internal/browser` 的认证界面、标签页显示与相关测试，以及主窗口状态的图形验收。不改变认证协议和凭据存储方式。
