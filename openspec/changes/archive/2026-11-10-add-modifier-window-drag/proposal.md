# Proposal

## Why

GhostFish 窗口目前只能通过标签栏中的空白区域拖动，网页占据大部分窗口时，调整窗口位置需要先找到该区域。macOS 用户需要通过可配置的修饰键，从窗口内容区域移动窗口，同时保留未触发拖动时的网页和控件交互。

## What Changes

- 在 macOS 上，按住所选修饰键组合后，从窗口内容区域任意位置按住鼠标左键并拖动，即可移动整个窗口；松开左键结束拖动。
- 默认使用 Command。设置界面支持从 Command、Control、Option 和 Shift 中选择一个或多个键，匹配时只接受完全一致的组合。
- 未匹配组合的鼠标事件保持原有行为。匹配组合时，允许拦截没有产生位移的单击；实际开启点击穿透时，窗口仍不接收鼠标事件。
- 优先使用 macOS 原生窗口移动能力，并保留现有窗口位置记录与恢复行为。Windows 和 Linux 不增加本功能或设置入口。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

- `browser-window`：增加 macOS 修饰键加左键拖动窗口的行为和交互边界。
- `settings`：增加拖动修饰键组合的选择、保存、校验及旧配置兼容规则。

## Impact

- 影响 macOS 窗口事件处理、设置界面和状态文件的读取与保存；现有四组全局快捷键保持独立。
- 需要验证原生窗口事件在网页视图、应用控件、后台窗口和多显示器环境中的行为。
- 不修改第三方网页，也不改变 Windows 和 Linux 的窗口交互。
