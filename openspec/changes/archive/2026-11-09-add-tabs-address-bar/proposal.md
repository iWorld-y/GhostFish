# Proposal

## Why

GhostFish 目前只能在启动时打开一个网址，切换站点需要关闭并重新启动应用。增加标签页和地址栏后，可以在同一个浮动窗口中打开和切换多个网页。

## What Changes

- **BREAKING**：启动命令不再要求网址参数；未提供网址时打开一个空白标签页，提供网址时在第一个标签页中加载该网址。
- 在窗口顶部放置标签栏；仅尚未打开网页的新标签页显示下一行地址栏。macOS 窗口的红绿灯与标签栏位于同一行。
- 支持新建、切换和关闭标签页；新建标签页显示空白页并聚焦地址栏，打开网页后隐藏地址栏，关闭最后一个标签页时关闭窗口并退出。选中标签使用上角圆润的轮廓并显示关闭按钮，其他标签平铺并用分隔线区分。
- 地址栏只接受网址。省略协议时补全 `https://`，不提供关键词搜索。
- 在地址栏打开需要 HTTP Basic 认证的站点时，继续使用现有凭据获取、校验和重试限制规则。
- 保留窗口置顶、透明度、点击穿透、隐藏和现有全局快捷键。标签页不跨应用重启恢复。

## Capabilities

### New Capabilities

- `browser-navigation`：管理同一窗口内的标签页，并通过新标签页地址栏打开网址。

### Modified Capabilities

- `browser-window`：启动网址由必填改为可选，未提供时打开空白标签页。
- `http-auth`：认证流程适用于启动网址和窗口打开后从地址栏加载的网址。

## Impact

- 启动参数、窗口创建、网页视图、地址解析和 HTTP Basic 认证流程需要调整；已有相关测试和 README 需要更新。
- 继续使用 MyGo 和系统 WebView，保留 macOS、Windows 和 Linux 的现有支持范围。
- 不增加搜索引擎、书签、浏览历史或跨重启恢复标签页。
