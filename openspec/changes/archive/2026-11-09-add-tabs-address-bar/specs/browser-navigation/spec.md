# Spec Delta

## Purpose

让用户在同一个浮动窗口内打开、切换和关闭多个网页，并通过尚未打开网页的新标签页地址栏输入网址。

## ADDED Requirements

### Requirement: 窗口顶部提供标签栏和新标签页地址栏

应用 SHALL 在网页内容之外显示标签栏，并仅在当前标签页尚未打开网页时显示地址栏。标签栏与窗口按钮位于同一行；地址栏可见时位于下一行，窗口保留可拖动区域。

#### Scenario: macOS 窗口布局

- **WHEN** 用户打开 macOS 窗口
- **THEN** 原生红绿灯按钮位于标签栏左侧；新标签页的地址栏位于标签栏下方，网页显示在其下方

#### Scenario: 其他平台的窗口按钮

- **WHEN** 用户在 Windows 或 Linux 打开窗口
- **THEN** 标签栏为平台显示的窗口按钮留出空间，已显示的按钮仍可正常使用

#### Scenario: 拖动窗口

- **WHEN** 用户拖动标签栏中用于拖动的空白区域
- **THEN** 窗口跟随移动，标签和地址栏仍可操作

### Requirement: 用户可以管理多个标签页

应用 SHALL 支持创建、切换和关闭标签页。每个标签页保留自己的网页状态，标签栏 SHALL 显示可区分的名称。当前标签 SHALL 具有上角圆润的轮廓并在内部显示关闭按钮；未选中标签 SHALL 平铺并以必要的竖线分隔。`+` 紧随标签列表，标签过多时 SHALL 保持可访问并可横向滚动。

#### Scenario: 新建空白标签页

- **WHEN** 用户点击标签栏中的 `+`
- **THEN** 应用打开并选中新空白标签页，地址栏获得输入焦点

#### Scenario: 切换标签页

- **WHEN** 用户从一个标签页切换到另一个标签页后再切回
- **THEN** 原标签页仍保留切换前的网页和滚动位置；已经打开网页的标签页不显示地址栏

#### Scenario: 关闭非最后一个标签页

- **WHEN** 用户关闭当前标签页且窗口中仍有其他标签页
- **THEN** 被关闭的标签页及其网页被移除，窗口继续显示一个未关闭的标签页

#### Scenario: 关闭最后一个标签页

- **WHEN** 用户关闭窗口中最后一个标签页
- **THEN** 窗口关闭，应用退出

### Requirement: 仅新标签页显示地址栏

应用 SHALL 为尚未打开网页的新标签页显示地址栏，并为各标签页独立记录是否已经打开网页。主文档首次提交后 SHALL 隐藏该标签页的地址栏，并让网页占用释放的空间；不得因当前网址变为空而将已打开的标签重新视为新标签。

#### Scenario: 新标签页打开网页

- **WHEN** 新标签页提交的网址开始导航且主文档已提交
- **THEN** 地址栏隐藏，无需等待页面的慢速子资源加载完成

#### Scenario: 带网址启动

- **WHEN** 应用带网址启动并开始加载首个标签页
- **THEN** 该标签页不显示地址栏

#### Scenario: 首次加载失败

- **WHEN** 尚未成功打开网页的标签页加载失败，包括重定向目标无法连接
- **THEN** 地址栏显示原始提交网址和错误提示，允许修改后重试

#### Scenario: 加载中重新提交网址

- **WHEN** 新标签页的首次网页仍在加载，用户再次提交网址，包括同一个网址
- **THEN** 被取代加载的回调不得覆盖新请求，输入和焦点保留，其他标签及共享会话不受影响

#### Scenario: 已打开的页面开始后续导航

- **WHEN** 首个网页已提交但仍在加载资源，用户从该页面继续导航，旧加载随后失败或取消
- **THEN** 地址栏保持隐藏，旧失败不得将该标签页恢复为新标签

#### Scenario: 切换到空白标签页

- **WHEN** 用户切换到尚未打开网页的标签页
- **THEN** 应用显示该标签页的地址栏，并保留尚未提交的输入及错误提示

#### Scenario: 已打开标签页跳转到空白页面

- **WHEN** 已打开网页的标签页随后导航到空白页面
- **THEN** 该标签页仍不显示地址栏

### Requirement: 地址栏只打开网址

地址栏 SHALL 接受 HTTP 或 HTTPS 网址并在当前标签页打开；输入省略协议时 SHALL 补全 `https://`。地址栏 SHALL NOT 将输入发送到搜索引擎。

#### Scenario: 输入不带协议的网址

- **WHEN** 用户在地址栏输入 `example.com` 并按回车
- **THEN** 当前标签页打开 `https://example.com`

#### Scenario: 输入 HTTP 网址

- **WHEN** 用户在地址栏输入以 `http://` 开头的有效网址并按回车
- **THEN** 当前标签页按输入的 HTTP 网址打开

#### Scenario: 输入无效网址或不支持的协议

- **WHEN** 用户提交无法解析的网址或非 HTTP、HTTPS 协议的网址
- **THEN** 应用提示输入无效，保留地址栏和输入供修改，不执行搜索

#### Scenario: 提交空地址

- **WHEN** 用户在空地址栏按回车
- **THEN** 应用保留地址栏，不发起导航或搜索
