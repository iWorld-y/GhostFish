# Spec Delta

## MODIFIED Requirements

### Requirement: 只在服务器要求 Basic 认证时介入

应用 SHALL 在加载启动参数或地址栏提交的网址之前，用一次请求判断目标站点是否需要 HTTP Basic 认证；不需要认证、探测失败或网址里已带凭据时，SHALL 按原样加载，不产生认证提示。

#### Scenario: 站点要求 Basic 认证

- **WHEN** 启动时目标网址的首次请求返回 401，且质询方式为 Basic
- **THEN** 应用进入取凭据流程，并在窗口出现前把凭据准备好

#### Scenario: 地址栏网址要求 Basic 认证

- **WHEN** 用户在空白标签页或已有标签页的地址栏提交网址，且目标网址首次请求返回 Basic 认证质询
- **THEN** 应用按现有顺序尝试获取凭据；获得凭据后校验并交给当前标签页，未获得时照常加载并在终端说明

#### Scenario: 普通站点

- **WHEN** 目标网址返回 200，或返回 401 但质询方式不是 Basic
- **THEN** 应用不询问凭据，目标网页照常加载

#### Scenario: 网址里已经带了凭据

- **WHEN** 启动参数或地址栏提交的网址形如 `https://用户名:密码@主机/`
- **THEN** 应用不再探测、不再询问，交给对应标签页自己使用网址里的凭据

#### Scenario: 不提供启动网址

- **WHEN** 用户未提供启动网址，应用打开空白标签页
- **THEN** 应用不为该空白页发起 HTTP 认证探测或询问凭据

#### Scenario: 多个主机的认证质询

- **WHEN** 不同标签页分别打开要求 Basic 认证的不同主机
- **THEN** 应用只将为目标主机准备的凭据交给该主机的 Basic 质询，并分别限制被拒凭据的重试次数
