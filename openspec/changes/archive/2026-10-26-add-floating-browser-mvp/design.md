# Design

## Context

仓库此前为空，本变更建立第一个可运行的程序。约束来自框架与平台：Go 1.27.3，桌面框架用 mygo（单文件二进制、纯 Go、不依赖 cgo），窗口里跑的是系统自带的 webview（macOS WKWebView / Windows WebView2 / Linux WebKitGTK），因此渲染效果和站点兼容性由各平台 webview 决定，不是 Chromium。

需求见 `specs/`，动机见 `proposal.md`。

关键前提已经在本机文档里核实过，不需要自己写平台层：

- 窗口选项有 `Opacity`（0–1）、`AlwaysOnTop`、`Transparent`、`StateKey`，运行时对应 `SetOpacity`、`SetAlwaysOnTop`、`SetIgnoreMouseEvents`。
- `SetIgnoreMouseEvents(true)` 让点击穿到窗口后面的内容。
- 全局快捷键是 `mygo.GlobalShortcut.Register`，在应用处于后台时也生效。
- 窗口可以直接 `LoadURL` 一个外部网址；框架也有菜单栏托盘能力，但本版不用。

## Goals / Non-Goals

**Goals:**

- 用一个 Go module 加一个主程序跑起来，不引入前端工程、npm 依赖和构建链。
- 四个动作（降透明度、升透明度、切穿透、隐藏/显示）在窗口穿透、隐藏、失焦时都能用。
- 状态（位置、尺寸、不透明度、穿透）跨重启保持。

**Non-Goals:**

- 不做页面注入、不改造第三方站点外观（属于后续"真透明"变更）。
- 不做多窗口、标签、地址栏。
- 不做菜单栏图标与托盘菜单（后续预研）、应用图标与配置文件。
- 不做打包分发（app bundle、签名、自动更新）。

## Decisions

**1. 窗口不透明度用整窗 `Opacity`，不用 `Transparent`。**
`Opacity` 对任意站点都成立，一行设定；`Transparent` 要求页面自身背景是透明的，第三方站点做不到，除非往页面里注入 CSS。代价是文字跟着变淡，低值可读性差，所以下限设在 20%、默认 85%。真透明（背景透、文字清晰）留给后续变更，届时需要引入应用自有前端或页面注入。

**2. 直接载入外部网址，不建前端目录。**
窗口用 `Page().LoadURL("https://…")` 载入目标站点，省掉 Vite/Bun 一套。代价是拿不到 `mygo://` 自有页面，页面不能调用 Go 方法；本变更不需要。若后续要做真透明或自有设置页，再补 `SetFrontend`。

**3. 控制面只有全局快捷键，不做托盘菜单。**
穿透开启后窗口不接收鼠标，窗口内的任何控件都点不到，所以控制条放窗口里等于自断退路。本版连菜单栏图标也不做：终端启动、快捷键控制，够用且少一块要维护的 UI。代价是快捷键被系统挡住时没有第二条入口，所以注册失败必须让用户当场看见（见决策 4）。托盘图标与菜单留作后续预研，等真的遇到快捷键冲突再补。

**4. 键位固定，注册失败输出到终端。**
默认 `⌘⇧−` / `⌘⇧+` 调透明度、`⌘⇧T` 切穿透、`⌘⇧H` 隐藏显示。不做自定义键位，也不读配置文件。没有托盘图标可挂提示，失败信息就写进启动应用的终端输出，指明哪个键位不可用；四个键位全失败时还要警告用户已无法切穿透或隐藏。备选方案是让用户编辑配置文件换键位，留到需要时再做。

**5. 状态分两处保存。**
位置和尺寸交给窗口自己的 `StateKey`（框架内建，格式由框架管）；不透明度和穿透状态写成一个小 JSON 放在用户数据目录（`App.Path(PathUserData)`），读取失败或越界就取默认值。分开是因为前者由框架负责，后者要参与业务判断。

**6. 不常驻 Dock。**
摸鱼场景里 Dock 图标本身就很显眼，本版又没有菜单栏图标兜底，所以应用以不占 Dock 的方式运行，终端里启动、窗口里用、关窗口即退出。需要注意 macOS 上这类应用默认不抢键盘焦点，窗口的输入行为要实际验证；如果焦点行为不可接受，退回普通应用模式，把 Dock 图标的事留给后续。

**7. 隐藏用 `Hide()`，不是销毁窗口。**
隐藏时页面和播放继续，恢复后回到原地址与滚动位置；真正退出只在关闭窗口时发生。

## Risks / Trade-offs

- [低透明度下读不清内容] → 默认 85%，20% 为下限；本版没有面板显示当前值，靠快捷键一步步拨回。
- [全局快捷键与其他应用冲突，尤其 `⌘⇧+`] → 注册失败立刻在终端报出键位；没有托盘兜底，这是本版已知的薄弱点。
- [穿透开启后用户找不到窗口的鼠标退路] → 默认不穿透；启动即穿透时快捷键照常注册；四个键位全失败时强制以不穿透、不隐藏启动。
- [第三方站点在 WKWebView 里兼容性不如 Chromium：登录态、第三方 cookie、UA 判断] → 先用真实目标站点验证；不兼容时优先改 UA，再考虑注入。
- [不占 Dock 的应用在 macOS 上的焦点与激活行为与普通应用不同] → 作为第一批要真机验证的点，不可接受就退回普通应用模式。
- [没有前端目录时 `mygo build` 是否接受需要验证] → 若必须，放一个最小的 `dist/index.html` 占位，不影响载入外部网址。

## Migration Plan

新项目，无迁移。首个可运行版本即为 v0.1；不兼容风险只存在于后续变更。

## Open Questions

- 快捷键被占用时是否需要换键位，等真机上撞到了再定；本版不做配置。
- 菜单栏图标与托盘菜单的形状和时机，作为后续预研项，本版不碰。
