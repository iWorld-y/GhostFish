# Proposal

## Why

上班时想瞄一眼某个网页，普通浏览器窗口太显眼，同事一眼就看见。需要一个能浮在别的窗口上面、可以调得很淡、必要时连鼠标点击都让过去的窗口，让自己看得见、别人不容易注意到。

## What Changes

- 只在终端启动：命令后面必须跟一个网址，缺参数直接报错退出，不读配置文件，不做应用自带前端。
- 窗口默认置顶，透明度可在 20%–100% 之间调整，步进 10%，重启后沿用上次的值。
- 新增点击穿透开关：打开后窗口不接收鼠标事件，点击落到它下面的窗口上。
- 因为穿透后窗口自身点不动，控制只剩全局快捷键这一条路：调透明度、切穿透、隐藏/显示窗口。本版不做菜单栏图标和托盘菜单。
- 记住窗口位置和大小，下次启动回到原处。
- 范围外（本变更不做）：菜单栏图标与托盘菜单（作为后续预研）、应用图标、配置文件、地址栏、多标签、书签、历史、下载、登录态管理、页面内容注入。
- 无 **BREAKING** 变更，本项目此前没有已发布行为。

## Capabilities

### New Capabilities

- `browser-window`: 终端启动时按必填参数载入一个外部网址，窗口的基本形态、可移动可缩放、以及位置和尺寸在重启后恢复。
- `window-appearance`: 窗口置顶与透明度调节，包括允许的取值范围、调整步进和重启后沿用上次取值。
- `click-through`: 鼠标点击穿透的开启与关闭，以及穿透状态下窗口不再响应鼠标、键盘焦点仍可保留的行为。
- `control-surface`: 全局快捷键作为穿透或隐藏状态下的唯一控制入口，覆盖全部动作，并在键位不可用时给出可诊断的结果。

### Modified Capabilities

无。项目此前没有已归档的能力规格。

## Impact

- 新增 Go module 与主程序，依赖 `github.com/egoist/mygo`。
- 新增：终端参数解析与校验、全局快捷键注册、窗口状态持久化。
- 无前端构建产物与 npm 依赖，窗口直接载入外部网址。
- 无菜单栏图标与应用图标，隐藏窗口后用户只能依靠快捷键找回，这是本版刻意的取舍。
- 平台：macOS 12 及以上；Linux 需 GTK 3 与 WebKitGTK 4.1；Windows 10/11 需 WebView2 运行时。透明与穿透由框架提供，不需要 cgo 或平台专用分支。
- 已知限制：整窗透明度会连同文字一起变淡，低透明度下可读性下降；真透明（背景透、文字清晰）留待后续变更。
- 后续预研（不在本变更实现）：菜单栏图标与托盘菜单，用来在快捷键被占用时兜底，并让应用不依赖终端会话存活。
