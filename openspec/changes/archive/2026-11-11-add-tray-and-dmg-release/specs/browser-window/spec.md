# Spec Delta

## MODIFIED Requirements

### Requirement: 启动网址参数可选

应用 SHALL 支持从终端启动，macOS 应用 SHALL 额外支持从 Finder 等图形入口启动。终端启动时可以提供网址；未提供网址或从图形入口启动时，应用 SHALL 打开一个空白标签页。

#### Scenario: 命令带上网址

- **WHEN** 用户在终端以网址作为唯一参数启动应用
- **THEN** 应用打开一个窗口，在第一个标签页载入该网址且不显示地址栏；首次加载失败时允许在地址栏修改后重试

#### Scenario: 缺少网址参数

- **WHEN** 启动命令不带网址参数
- **THEN** 应用打开一个包含空白标签页的窗口，并将输入焦点放在地址栏

#### Scenario: 网址无法解析

- **WHEN** 启动命令显式提供无法解析或协议不受支持的网址
- **THEN** 应用向终端报告错误并以非零状态退出，不静默打开空白页

#### Scenario: 网址缺少协议

- **WHEN** 启动参数是未指定协议的有效网址
- **THEN** 应用补全 `https://` 后在第一个标签页中载入

#### Scenario: 多余参数

- **WHEN** 启动时给出多个网址参数
- **THEN** 应用只载入第一个网址，其余被忽略且不报错

#### Scenario: 图形入口启动 macOS 应用

- **WHEN** 用户从 Finder 打开已安装的 `GhostFish.app`
- **THEN** 应用无需终端即可打开包含空白标签页的窗口，并将输入焦点放在地址栏

#### Scenario: 图形启动后访问需要认证的站点

- **WHEN** 用户从图形入口启动应用后，在地址栏输入需要 HTTP Basic 认证的网址，但没有可用的终端或已保存凭据
- **THEN** 应用不得等待终端输入，按现有认证回退规则将加载交给系统 WebView 处理
