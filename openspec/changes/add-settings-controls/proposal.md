# Proposal

## Why

GhostFish 的不透明度范围和四组全局快捷键目前固定在代码中，用户无法按使用习惯调整。设计稿提出了设置入口，需要将设置界面、保存行为和窗口恢复方式明确为可验证的功能。

## What Changes

- 在 macOS 标签栏右侧提供设置入口，用于编辑不透明度上下限和四组全局快捷键；保存前允许取消编辑。
- 按最新设计调整 macOS 标签栏：当前标签使用直角并占满栏高，标签整体提供悬停反馈，新建按钮的加号居中。
- 不透明度上下限允许设置为 0% 至 100% 的整数，默认范围也是 0% 至 100%，默认当前不透明度仍为 85%；保存后将当前值限制在新范围内；快捷键仍按 10 个百分点调整。
- 允许录入并保存四组不重复的快捷键；在系统报告注册失败时提示原因，并按已知注册结果保护窗口。
- macOS 快捷键采用非独占注册，允许与其他应用共享；在设置中提示共享及拦截风险，不把注册成功视为快捷键一定可用。
- 保存设置供后续启动使用，兼容已有状态文件。保存设置和注册快捷键失败时给出明确反馈。
- 保留标签页、地址栏、网页、窗口穿透与隐藏的既有行为，不增加托盘、菜单栏图标或置顶开关。Windows 和 Linux 暂不提供本次新增设置，保持现有行为。

## Capabilities

### New Capabilities

- `settings`: 设置入口、编辑与取消、输入校验、设置保存和重启恢复。

### Modified Capabilities

- `browser-navigation`: 在标签栏加入设置入口，同时保留平台窗口按钮、标签操作及拖动区域。
- `control-surface`: 支持配置和共享全局快捷键，并处理可检测的注册失败、恢复和录入时的动作隔离。
- `click-through`: 根据穿透快捷键的已知注册结果决定启动时是否恢复穿透，并说明注册成功不保证按键一定送达。
- `window-appearance`: 允许在原有安全范围内配置不透明度上下限，并按新范围限制当前值。

## Impact

- 原生界面、窗口状态、全局快捷键、macOS 连续按键处理及对应测试需要调整；现有网页不注入应用界面。
- 需要验证 MyGo 在 macOS 的快捷键重新注册、键盘录入和设置界面能力；Windows 和 Linux 保持原有控制行为。
- README 和 OpenSpec 规格需要更新。现有规格中「关闭置顶」与实现不一致的问题不属于本次范围。
